## 🌐 Cara Mengaktifkan Laman Web Rasmi di GitHub Pages

Apabila anda memuat naik repository ini ke GitHub, **GitHub hanya memaparkan fail kod sumber dan dokumentasi README secara lalai**.

Untuk mengaktifkan laman web rasmi interaktif supaya boleh dilayari secara dalam talian (*Live Web App*):

1. Pergi ke Repository GitHub anda (contoh: `https://github.com/<username>/DB-Fundamentals`).
2. Klik tab **Settings** ⚙️ (di bahagian atas kanan repository).
3. Di panel tepi sebelah kiri, klik **Pages**.
4. Di bawah seksyen **Build and deployment** ➔ **Branch**:
   - Pilih branch **`main`** (atau **`master`**).
   - Pilih folder **`/ (root)`**.
5. Klik **Save**.
6. Tunggu 1 - 2 minit untuk GitHub siap membinanya.
7. Laman web rasmi anda kini secara automatik boleh dilayari di URL:
   👉 **`https://<username>.github.io/DB-Fundamentals/`**
